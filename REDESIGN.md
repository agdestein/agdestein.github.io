# Atmospheric website redesign

## Direction

Build a distinctive personal publication site in Astro, with Vue islands for
interactive scientific figures. Keep a consistent reading experience while
Aurora, Desert, Coffee, Alpine, Rainforest, and Ocean change the surrounding
environment and shared palette.
The first deliverable is a working design prototype, not a production cutover.

## Workspace

Develop in `redesign/`, inside the existing Git repository. A second repository
would make it harder to review content reuse and migration together. The current
VitePress site and deployment remain available throughout the prototype.
Reuse the existing publication/talk data and static assets rather than duplicating
them. No production deployment or push is part of this step.

- [x] Production build and a documented local preview command.

## Design rules

Use a vivid landscape at the opening, quiet reading surfaces below it, and sparse
decorative details. Keep a consistent type system and layout across themes.
Artwork and synthetic demonstrations must be clearly distinguishable from measured
research data. Scientific series keep stable semantic identities, supplemented by
labels and line styles. Theme changes never alter numerical data.

Use CSS/SVG for the landscape and a small optional WebGL layer for atmospheric
motion. Keep an attractive static fallback. Pause rendering when hidden or off
screen; bound rendering resolution on high-density displays. Reduced-motion
preferences disable ambient motion by default.

On phones, recompose the landscape and put figure controls below the plot.
Do not shrink scientific labels into illegibility. Long equations and data tables
may scroll inside their own containers, never make the whole page overflow.

## Content structure

Navigation: Writing, Publications, Talks, Software, About (including CV).
Research hubs are not part of the primary navigation. Existing work identifiers
remain compatibility metadata for this prototype. In the final migration,
replace single-work ownership with optional topic arrays and explicit related links.
Do not silently delete existing URLs or lose publication thumbnails while removing
the hub structure.
