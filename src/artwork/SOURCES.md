# Logo-inspired entry artwork

These are decorative adaptations for Syver's CV and software entries, not official
institutional lockups. Colors follow the active atmosphere. Small secondary text
and crests are omitted where they would be unreadable.

| Artwork | Reference | Adaptation |
| --- | --- | --- |
| `cwi.svg` | [CWI website logo](https://www.cwi.nl/static/images/logos/cwi-logo-english-white.svg) | Original plate and letter cutouts; tagline removed, rotated, recolored, without surrounding ornament. |
| `inria-polytechnique.svg` | [Inria wordmark, Dragon Rouge, archived on Commons](https://commons.wikimedia.org/wiki/File:Inr_logo_rouge.svg); [École Polytechnique](https://www.polytechnique.edu/) | Inria script outline over a redraw of Polytechnique's sweeping X; separate scales and angles; each mark uses one color. |
| `tue.svg` | [TU/e](https://www.tue.nl/en/) header SVG | Original TU/e outlines, with all letters and the slash in one theme color. |
| `insa.svg` | [INSA Toulouse logo](https://www.insa-toulouse.fr/wp-content/uploads/2022/10/Logo_INSAvilletoulouse-RVB-carre.jpg) | Vector outline traced from the original heavy capitals and detached wedge, including the original S shape. |
| `irt-saint-exupery.svg` | [IRT Saint Exupéry logo](https://www.irt-saintexupery.com/wp-content/uploads/2021/02/logo_IRT-Saint-Exupery.png) | Simplified arch of concentric bands, tilted and recolored. |
| `polytech.svg` | [SPbPU Polytech mark](https://english.spbstu.ru/local/templates/main/img/polytech-logo-en-small.svg) | Original pi-shaped cutout in a tilted square; wordmark omitted for the nested CV size. |
| `ins.svg` | [IncompressibleNavierStokes.jl logo source](https://github.com/agdestein/IncompressibleNavierStokes.jl/blob/main/docs/src/public/logo.svg) | All four original vortex curves, rotated and recolored with the four theme-series colors. |

Reference files inspected on 17 September 2026. No remote asset requests are
needed at runtime. SVGs contain only geometry and theme variables; editor
metadata, source styles, external references, and IDs are omitted.
